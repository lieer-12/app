# Phase 5 文件基础契约（第七批，尚未开放设置入口）

本批只完成导出 / 输入预览的底层文件能力。没有恢复或清空数据库的 API，
没有系统选择器、确认状态机或设置按钮；不能据此宣称 Task 5 或 Phase 5 完成。
JSON 字段、版本、行数及 SHA-256 规则仍以 `backup-format-v1.md` 为准。

## 分层和准入

- domain 定义不依赖 Android 的 `BackupLocation`、`BackupFileStore`、
  `BackupFileUseCases` 和预览计数；data 使用 `ContentResolver`。
- Hilt 绑定文件仓库，并为文件用例提供现有备份仓库、codec、同一全局维护协调器
  和 IO dispatcher。这是供后续 ViewModel 注入的真实底层，不是已接线的 UI 功能。
- 普通导出在原世代许可内读取 Room 单事务快照，许可结束后编码、写文件。
  不在文件提供方操作期间持有普通许可、Room 事务或模块 Mutex。
  维护已开始时拒绝新快照；快照完成后的文件写入可以与维护重叠，不修改新库。
- `writeVerified` 只接受已有完整文档，供将来的保护备份流程复用；它不获取
  嵌套许可，不替代维护会话、保护备份选择和确认。输入预览只读，不访问当前库。
- 编解码和文件操作使用注入的后台 dispatcher；后续 UI 发布仍必须检查原操作身份 / 世代。

## 导出成功的定义

1. codec 严格验证并生成完整 UTF-8 文件；超限或错误快照不打开输出。
2. 仅接受带 authority 的 `content:` 文档，不支持直接数据库路径或网络 URL。
3. 使用 `wt` 请求截断输出，分块写入、flush、close；任何一步失败都不报告成功。
4. 关闭输出后重新打开同一 URI，受限读取，再经过完整 JSON / SHA-256 / 结构校验。
5. 解码的整个文档必须与本次导出的文档一致；另一份校验正确的备份也不能冒充本次成功。

不会删除用户选择的输出文件，亦不能承诺文件提供方的跨设备持久落盘或原子写入。
失败可能留下残片、旧文件，或者已写完但未确认成功的文件；不能把失败当作已完成保护备份。
今后作为恢复输入时必须重新完整校验。文件是明文，SHA-256 不是加密、认证或隐私保护。

## 输入预览和清理

- 不信任 `available()`、声明长度或提供方 metadata；按实际读到的字节计数。
- 默认 64 MiB；只读多余的一字节判定超限，不把该字节写入私有临时文件。
  零字节进展的流用单字节读取推进，不循环忙等；空输入由 codec 判为非备份。
- 输入先复制到 `cacheDir/backup-inputs` 的随机 `input-*.tmp` 文件，关闭来源和
  临时输出后，再读取该私有副本作完整校验。URI 和提供方文件名不参与本地路径拼接。
- 成功 / 校验失败 / IO 失败 / 协程取消均在 finally 中清理本次确切创建的文件。
  清理是 NonCancellable；不递归删除目录、不扫无关文件、不删除来源或保护备份。
  主错误保留，清理失败附加为 suppressed；单独清理失败则不返回成功预览。
- 预览计数来自校验后的真实表，保留十表 75 字段、Long 精度和设置，不使用假数据。

## 验收边界与后续必做

- 流单测用真实字节流和局部故障注入；Robolectric 测真实 `ContentResolver` / provider
  的 URI 拒绝、权限错误和 `wt` 截断。仪器测试用 API 35 的真实 Downloads provider
  和独立合成 Room 库，验证十表文件往返以及损坏 / 删除输入不改库。
- 仪器测试仅插入带随机 UUID、`IS_PENDING=1` 的未发布合成文档；finally 只删除
  本次 insert 返回的确切 URI。测试不访问应用用户库，不安装生产测试 provider。
- 这不是 SAF 文件选择器、云提供方、磁盘耗尽、实际权限撤销、进程杀死或数据库恢复验收。
- 阻塞型 provider 调用的取消是协作式检查，不承诺立即打断 Binder / 原生 IO。
  文件和 codec 仍会分配受限字节数组 / JSON 对象，64 MiB 不等于 64 MiB 峰值内存。
- 强制杀进程来不及 finally，可能留有私有 cache 残片；本批不恢复任何操作。
  开放入口前必须补启动时仅清理已确认失去所有者的本应用临时文件、进程死亡状态重置测试。
- 下一批接入来源与保护输出去重、二次确认、会话所有权、原子替换 / 清空与世代推进、
  保留 / 失效草稿、成功 / 取消 / 失败后的提醒校准，再完成完整提醒载荷和设置保护。
