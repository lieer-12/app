# UI 改版验收记录

## 2026-10-08 · 第一批：卡通手账主题、导航与待办

用户在本轮明确要求开始 UI 改版，并批准生成图中的卡通手账方向。本次改变的是 UI 工作顺序，不表示 Phase 5 的稳定 60 fps 或真机性能已通过。设计在对话中批准，本批只修改既有界面的视觉和可访问性，不新增业务功能。

### 实现范围

- Material 3 预设浅色/深色配色：奶油纸色、薄荷绿、珊瑚橙、暖墨绿；继续使用 Room 保存的浅色/深色/跟随系统选择。改用预设色而非 Android 12+ 壁纸动态取色，符合需求允许的主题方案。
- 全局系统字体层级、圆角与卡片表面；四个业务模块和设置仍是原有五个导航项，不加入首页、空模块或新导航行为。
- 待办顶部、真实今日统计与读屏进度、筛选、卡片、加载/错误/空状态、珊瑚色新增按钮。完成状态有 180 ms 颜色过渡，使用 Compose 动画时钟，不添加常驻装饰循环动画或关闭系统动画。
- 小型原生 Canvas 清单插画由批准的 AI 视觉预览指导；不下载字体或图片，不把整屏效果图作为 UI，不添加个人资料、奖励系统、示例数据或网络依赖。插画无独立读屏节点；加载状态使用 Material 标准进度指示，不添加常驻装饰循环动画。
- 待办筛选与列表共用滚动容器；打开搜索主动显示输入框；筛选无结果与日期无记录分别说明，不暗示已删除数据库中的记录。
- 系统栏图标随浅深模式调整；底部导航与系统导航栏分离，内容消耗已处理的窗口边距。

### 不变约束

Room schema、持久化实体、Repository、Use Case、ViewModel、构建版本、Manifest、通知与备份流程不因视觉改版而变化。维护期间禁用入口、实时点击校验、每个目的页的返回保护、通知跳转与草稿保留继续保留。已有 Phase 5 工作区改动不回退、不覆盖，不使用 destructive migration。

### 验证结果

- TDD 第一轮：14 项定向 JVM 测试，4 项预期失败；证明表面层次、读屏进度和筛选空状态原先缺失。随后发现滚动后的搜索入口不可见问题，增加滚回搜索框实现。
- API 35 独立只读模拟器：320dp 宽、200% 字体的浅/深色设备检查最初报告标题宽度裁切；增加标题可用宽度及可增长高度。进一步采集行边界发现有段落空白误报：`今日进度` 文本框 292px、段落 428px，但实际字行是 0–292px，高度一致。最终检查逐行真实左右边界及高度，而非把段落的尾部空白当作丢失的文字；同时检查滚动可达性及 48dp 新增/筛选触控区域，不降低字号、不跳过测试。
- 独立审查指出全局配色影响既有打卡日历的日期数字对比；只修复前景色配对，不提前进行打卡整页视觉改版。
- 最终全量命令成功退出（`BUILD SUCCESSFUL`，5 分 11 秒）：665 项 JVM / 67 套件、54 项 API 35 设备测试 / 23 套件，均 0 failure / error / skipped。新增浅深色紧凑窗口设备用例均通过，未以编译代替交互验收。
- Debug、测试 APK、Release 构建通过；lint 0 error / 57 warning，已有警告保留。Debug APK 19,350,922 字节；未签名 Release APK 12,248,656 字节，均小于 30 MB。未签名 Release 不是直接安装或正式发布包。
- 独立代码审查通过本批源代码，无剩余 P1/P2 问题；随后完成上述全量回归。`git diff --check` 通过，构建配置、Manifest 与数据库文件未因本批变化。
- 全量设备测试后重新安装最终 Debug APK，使用独立只读模拟器的真实空数据库检查浅深色截图；截图为实际界面，不是 AI 效果图。截图仅保留在忽略的 `.tools/ui-redesign-final-light.png` 和 `.tools/ui-redesign-final-dark.png`，不提交设备产物。切换深色通过真实设置页完成，不使用示例业务数据。
